# Act2. Spring MVC - Vistas con Thymeleaf, DTOs y Manejo de Peticiones

Proyecto de RestAPI con manejo de peticiones con clases DTO y vistas renderizadas con Thymeleaf en Spring desplegado en VPS (Hostinger).

## Funcionamiento
El proyecto consta de dos controladores, un @Controller y un @RestController, los cuales retornan dos vistas renderizadas con `Thymeleaf`, los controladores tambiene contienen los endpoints para el funcionamiento de renderizado de la lista de mascotas, mostrar los valores personalizados de las propiedades y sobre todo cargar los datos.

### Despliegue
El proyecto se encuentra desplegado y funcionando correctamente en este [link]([https://veterinariabobby.tech/eaecact2_t4/mascotas/lista](https://veterinariabobby.tech/eaecact3_t4/productos)) .
